## ?? Key Components

### 1. **Message Queue** (1-to-1)
```csharp
var queue = new InMemoryMessageQueue<OrderPlacedEvent>("orders");
await queue.PublishAsync(orderEvent);
var message = await queue.ConsumeAsync();
```

### 2. **Message Topic** (1-to-Many)
```csharp
var topic = new InMemoryMessageTopic<OrderPlacedEvent>("order-placed");
topic.Subscribe(async (order) => await ProcessInvoice(order));
topic.Subscribe(async (order) => await ProcessDelivery(order));
await topic.PublishAsync(orderEvent);
```

### 3. **Invoice Workflow**
- Generates invoice number
- Calculates VAT (19%)
- Prints formatted invoice
- Emits InvoiceGeneratedEvent

### 4. **Delivery Workflow**
- Calls delivery API (with Polly retry)
- Gets tracking number
- Prints shipping label
- Emits DeliveryInitiatedEvent

## ?? Patterns Implemented

### Event-Driven Architecture ?
- Events instead of direct calls
- Loose coupling between components
- Easy to add new subscribers

### Pub/Sub Pattern ?
- Topics for 1-to-many communication
- Multiple subscribers to one event
- Parallel processing

### Message Queue Pattern ?
- Queues for 1-to-1 communication
- Work distribution
- Backpressure handling

### Workflow Pattern ?
- Invoice generation
- Delivery initiation
- Event chaining
